# 🪷 Budismo — Vault

Una biblioteca viva de notas sobre el **Camino Budista**, con especial profundidad en la tradición **Gelug-Kadampa**, los **Yogas del Tantra Superior** (Vajrayogini, Seis Yogas de Naropa) y el **Sutra Mahāyāna**.

- ✍️ **[Autores](./03---autores)** — Maestros y comentaristas del linaje
- 💬 **[Citas](./04---citas)** — Pasajes destacados
- 🗺️ **[Índice completo](./00---índice)** — Mapa general del vault

## Explorá el conocimiento

Usá la **búsqueda** (arriba a la izquierda), el **explorador de archivos** (barra lateral) y el **grafo** (barra derecha) para navegar las conexiones entre ideas. Cada nota enlaza a las relacionadas, siguiendo la lógica de un *digital garden*.
